# MobileAutomation

MobileAutomation is an Appium-based Java test automation framework for mobile applications. It provides TestNG test suites, BrowserStack integration for cloud device execution, and example test configurations for Smoke and Regression runs.

## Tech stack
- Java 17
- Maven
- Appium Java Client
- Selenium
- TestNG
- BrowserStack (optional)

## Repository layout
- appium-2024-Appium_2024_Framework_FactoryMethod/  — main framework and test code (pom.xml, testng.xml, browserstack.yml)

## Requirements
- Java 17 or newer
- Maven
- (Optional) Appium server for local device/emulator testing
- BrowserStack account if running on BrowserStack. Set credentials via environment variables:
  - BROWSERSTACK_USERNAME
  - BROWSERSTACK_ACCESS_KEY
  Or configure browserstack.yml (do not commit secrets).

## Running tests
1. From the project root:
   cd appium-2024-Appium_2024_Framework_FactoryMethod
2. Run Smoke suite:
   mvn test -P Smoke
3. Run Regression suite:
   mvn test -P Regression

For local Appium testing, start the Appium server and ensure device/emulator is available. For BrowserStack runs, configure credentials and app/device settings in browserstack.yml or via environment variables.

## Reports
TestNG and Surefire reports are available under target/surefire-reports. Extent reports (if configured) will be generated by the test framework.

## Notes
Do not commit credentials. Use environment variables or secure secrets management to store API keys and access tokens.

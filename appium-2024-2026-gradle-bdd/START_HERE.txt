STEP 1: Get Your Percy Token
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Visit: https://percy.io/builds
  2. Create account or login
  3. Select or create a project
  4. Copy the "Project Token"

STEP 2: Set Your Token in PowerShell
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Run this command in PowerShell:

    $env:PERCY_TOKEN = "paste_your_token_here"

STEP 3: Run Tests
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Run this command:

    .\run-percy-tests.ps1

  That's it! 📸

For Local Appium Testing:
  • Make sure Appium is running:

    appium

  • Run in a SEPARATE PowerShell window
  • Keep it running while tests execute

For BrowserStack Testing:
  • Also set these environment variables:

    $env:BROWSERSTACK_USERNAME = "your_username"
    $env:BROWSERSTACK_ACCESS_KEY = "your_access_key"
    $env:BROWSERSTACK_APP_ID = "bs://your_app_id"

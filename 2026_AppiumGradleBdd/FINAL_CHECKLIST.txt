📸 SCREENSHOT FLOW

When you run tests:

  Test Feature File (visual.feature)
         ↓
  Cucumber Runner (CucumberVisualRunner)
         ↓
  Test Hooks (@Before) → TestHooks.setUp()
         ↓
  Initialize Appium Driver
         ↓
  Launch App on Device/Emulator
         ↓
  Test Steps (@When) → VisualSteps.i_take_percy_snapshot()
         ↓
  PercyHelper.snapshot() called
         ↓
  ├─ Appium captures screenshot from device
  ├─ Save to: build/percy-snapshots/
  ├─ Upload via Percy CLI (if PERCY_TOKEN set)
  └─ Display result (✓ success or ⚠ failure)
         ↓
  Test Hooks (@After) → TestHooks.tearDown()
         ↓
  Close Driver
         ↓
  Final Report

Result: Screenshots saved locally and uploaded to Percy.io

🆘 IF SOMETHING GOES WRONG

Quick Troubleshooting:

Error: "PERCY_TOKEN not provided"
  → Solution: $env:PERCY_TOKEN = "your_token_here"

Error: "npm is not installed"
  → Solution: Install Node.js from https://nodejs.org/

Error: "Appium server is not running"
  → Solution: Open new terminal and run: appium

Error: "Device not found"
  → Solution: Run: adb devices
  → Then: emulator -avd emulator-5554

Error: "Failed to create AndroidDriver"
  → Hint: Make sure device/emulator is unlocked
  → Try: adb shell input keyevent 82

Error: "Screenshots not uploading to Percy"
  → Check: Is PERCY_TOKEN set and valid?
  → Check: Is there network connectivity?
  → Fallback: Screenshots still saved locally

For More Help:
  → Run: .\validate-setup.ps1 (checks environment)
  → Read: PERCY_QUICK_START.md (see Troubleshooting)
  → Check: Console output for detailed error messages

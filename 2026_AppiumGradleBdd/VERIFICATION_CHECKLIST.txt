KEY ENVIRONMENT VARIABLES

These must be set for Percy to work:

PERCY_TOKEN (REQUIRED)
  Set by: You (from percy.io/builds)
  Used by: Percy CLI authentication
  Example: $env:PERCY_TOKEN = "eyJhbGc..."

PERCY_SERVER_ADDRESS (SET BY PERCY EXEC)
  Set by: percy exec command automatically
  Used by: PercyHelper to find Percy server
  Value: http://localhost:5338 (typical)
  Read by: PercyHelper in uploadToPercyServer()

PERCY_BUILD_NAME (OPTIONAL)
  Set by: You or run-percy-tests.ps1
  Used by: Percy dashboard to label build
  Default: "Visual Test Build - [timestamp]"

HOW IT WORKS NOW

1. percy exec starts
   └─> Percy server starts on localhost:5338
   └─> Sets PERCY_SERVER_ADDRESS=http://localhost:5338
   └─> Runs: gradlew test

2. Tests run
   └─> Appium launches app
   └─> Screenshot taken
   └─> PercyHelper.snapshot() called

3. PercyHelper uploads
   └─> Reads PERCY_SERVER_ADDRESS from environment
   └─> Creates HTTP POST request
   └─> Sends screenshot as base64 JSON
   └─> Gets HTTP 200 response
   └─> Percy server receives snapshot

4. Percy counts it
   └─> Snapshot added to build
   └─> Shows in dashboard
   └─> Available for comparison
